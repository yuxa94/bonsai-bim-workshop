# 03 · 기준층을 만들고 다른 층과 면적표로 확장하기

단위세대를 원점 주변에 늘어놓는 배치 연습 다음에는 **실제 동평면 DWG 한 층**을 해석합니다. 입력은 `A32-5-23F.dwg`입니다. 이 파일명만 보고 5~23층을 모두 적층하지 않습니다. 먼저 도면의 14세대·복도·코어가 있는 한 층을 작성하고 수정합니다.

`{WORKSHOP_ROOT}`는 수업 자료 폴더입니다. 직접 생성·수정은 `work/a32-floor-01/`, `work/a32-floor-02/`처럼 새 작업 폴더를 사용합니다. 제공 완성 IFC를 여는 활동은 직접 작성한 활동과 기록에서 구분합니다.

## 실제 동평면으로 기준층 작성

```text
$my-unit-bim
입력은 {WORKSHOP_ROOT} 안의 A32-5-23F.dwg야.
기존 단위세대 창을 보존하고 별도 Blender 세션에서
이 도면의 기준층 한 층을 IFC로 만들어줘.

우선 CAD의 실제 기준층 범위와 세대 INSERT를 조사해줘.
중첩·미러 블록은 변환행렬로 WCS에 맞추고,
단위·기준점·회전·세대수·세대별 타입과 공용부를 정리해줘.
도면 밖의 참조 블록까지 모두 모델링하지는 마.
벽·문창·바닥·복도·계단·승강기의 관측값과 미표기 수직 치수를 구분하고
필수 질문을 모아줘. 아직 다른 층으로 복제하지 마.
```

실제 원본의 14세대 구성은 다음과 같았습니다. 원본의 세대 배치와 모델의 개수를 직접 대조할 때 사용합니다.

| 원본 타입 | 세대수 |
|---|---:|
| 25 | 6 |
| 54 | 4 |
| 57 | 1 |
| 65 | 1 |
| 84A | 1 |
| 84B | 1 |
| 합계 | 14 |

과거 한 층 실습은 벽 2800·슬래브 200·문 2200mm를 사용자에게 확인받았습니다. 이번 수업도 학생이 사용할 값을 답하고 진행합니다. 창대·가구·계단의 미표기 높이까지 함께 승인된 것으로 취급하지 않습니다.

```text
이번 기준층 실습의 검토 조건으로 벽2800·슬래브200·문2200mm를 적용해줘.
나머지 미표기 수직 치수는 부재별 가정으로 표시해줘.
원본의 14세대와 공용부를 포함한 편집 가능한 IFC로 작성하고,
저장본 재열기·GUID 중복·형상 생성·층 소속을 검사해줘.
기존 단위세대 자료와 다른 창은 유지하고,
원본 평면·모델 평면·입체를 같은 기준으로 비교해줘.
```

단위세대 라이브러리를 읽었다고 해서 모든 세대를 가장 가까운 종류로 대체하지 않습니다. 동평면에는 방향·미러·외벽 조건이 다른 배치형과 별도 57형이 있습니다. 모델이 원본과 다른 윤곽을 가지면 해당 차이를 먼저 조사합니다.

## 현재 기준층 수정

학생이 도면에서 확인할 위치 하나를 고르고 현재 IFC에서 고칩니다. 실제 작업에서는 계단 UP/DN·참, 문틀·문 상부 벽, 단열, 창 주변을 추가 보완했습니다.

```text
현재 기준층 IFC에서 원본과 다른 부분을 확인하고 수정해줘.
이번 대상은 계단의 UP/DN·계단참과 문 상부 벽이야.
현재 파일 경로와 미저장 상태를 먼저 확인하고 수정 전 IFC를 보존해줘.
원본 치수와 층 소속을 확인한 뒤 대상 부재만 수정해줘.
새 창으로 처음부터 다시 모델링하지 말고 현재 기준층의 변경을 이어가줘.
Save IFC 후 저장본을 다시 읽어 대상 형상과 기존 GUID 보존을 확인해줘.
```

여러 창에서 작업할 때는 창 제목·IFC 경로·연결 포트가 대응하는지 확인합니다. 현재 기준층을 수정하는 요청과 다른 층을 새로 만드는 요청을 구분합니다.

## 기준층 성공 뒤 두 번째 스킬 작성

```text
$skill-creator
방금 기준층을 작성하고 수정한 성공 기록에서 my-floor-bim 스킬을 만들어줘.
단위세대 작성 스킬을 무작정 길게 늘리지 말고,
동평면의 세대 INSERT·미러·공용부·층 레벨·반복과 예외 편집 규칙을 중심으로 써줘.

재사용할 때 필요한 항목은 다음과 같아.
- 기준층·다른 층·단면의 실제 범위와 레벨 근거
- 설계 타입과 방향·미러가 다른 배치형 구분
- 공용부 분리, IFC 공간 계층과 부재 소속
- 타입 원본 편집과 한 층 예외 편집의 차이
- 인스턴스별 GUID, 층별 파일과 통합 파일의 같은 부재 대응
- 새 IFC 검증과 면적표의 근거·한계

{WORKSHOP_ROOT}/my-skills/my-floor-bim/SKILL.md에 작성해줘.
이번에 아직 실제로 시험하지 않은 기능은 계획이나 후속 검증으로 적어줘.
```

[starter/floor-bim/SKILL.md](../skill-kits/starter/floor-bim/SKILL.md)로 초안을 채우고 [completed/floor-bim/SKILL.md](../skill-kits/completed/floor-bim/SKILL.md)와 비교합니다. 개인 스킬 경로 등록 방법은 [02 안내](02-first-unit-and-personal-skill.md)를 따릅니다.

## 다른 층으로 확장

실제 프로젝트는 수정한 기준층에서 6개 설계 타입·14개 배치형을 보관하고 공용부를 분리했습니다. 같은 타입의 발생 객체는 형상을 재사용하되 각각 새 GUID를 갖습니다. **통합 IFC와 층별 IFC의 같은 물리 부재는 GUID와 월드 좌표가 같게 유지**합니다.

```text
$my-floor-bim
기준층 수정본을 보존하고, 제공된 동평면·동단면을 읽어 다른 층을 구성해줘.
처음에는 대표 일반층 하나와 형상이 다른24층을 비교해줘.
층 이름만 바꿔 반복하지 말고 실제 레벨·세대수·공용부·테라스 차이를 확인해줘.

수정한 기준층의 세대와 공용부를 버전이 있는 보관본으로 나눠줘.
6개 설계 타입과14개 방향·미러 배치형을 구분해줘.
타입 원본을 고치면 반복층에 반영되고,
특정 층 예외는 그 층의 별도 수정본을 우선하도록 관리해줘.
단면의 치수 끝점으로 층 레벨을 정하고 FL/SL 상충은 알려줘.
```

수업에서는 일반층 한 곳과 24층의 차이를 직접 확인합니다. 상부·지하 전체 작성은 제공 완료 예제로 확장 흐름을 살펴볼 수 있습니다. 과거 결과는 3~23층 각14세대, 24층5세대, 합계299세대였으며 이후 지하5층~옥탑 지붕까지33개 층으로 확장되었습니다. 이 수치는 제공 모델의 사례 결과이며 수강생의 새 결과는 직접 세어 확인합니다.

층 복제에는 새 모델 파일이 필요하지만, 현재 기준층의 미저장 변경을 저장 없이 버리는 방식으로 진행하지 않습니다. 보관본은 불변 버전으로 유지하고 편집용 작업 사본을 만듭니다. 외부 IFC를 자동 추적하는 XRef나 실시간 양방향 병합이 완성된 것으로 소개하지 않습니다.

**반복·예외 편집 확인**

```text
납품본이 아닌 새 시험 사본에서 재사용 편집을 검증해줘.
제공된5층·6층 개별 IFC와 대응 유닛1개만 사용하고 전체 동 파일은 받거나 열지 마.
수정 전 파일을 보존한 뒤, 공유 타입의 높이 하나를 바꿔 두 층의 새 시험 사본을 만들어줘.
유닛 원본의 타입·매핑과 각 층 발생 객체의 대응을 기록하고,
두 층에 같은 변경이 반영됐는지 표본검사해줘.
별도 한 층 예외도 등록해 그 층만 달라지는지 검사해줘.
같은 물리 부재의 수정 전후에는 기존 GUID와 월드 배치를 대조하고,
다른 층에 새로 반복 배치한 발생 객체는 별도 GUID를 갖는지 확인해줘.
시험 파일·변경값·관측 결과와 자동 갱신되지 않은 부분을 남겨줘.
```

## 저장 IFC에서 면적표 만들기

이 과정은 모델을 더 수정하는 작업과 분리해 **저장된 IFC를 읽기 전용으로 분석**합니다. 표를 만들기 전 입력 IFC 경로·버전·SHA256·수량 기준을 기록합니다.

```text
현재 검토할 저장 IFC로 면적표를 만들어줘. 모델은 수정하지 마.
먼저 IfcSpace에 실제 공간 형상과 면적 수량이 있는지 조사해줘.
없다면 타입명25·54·57의 숫자를 면적으로 쓰지 말고,
슬래브 단면 등 사용할 수 있는 기하와 산정 경계를 설명해줘.

실습은 일반 바닥의 수평 XY 투영 합집합 면적으로 해줘.
층별·등록 세대별 집계, 계단참·지붕·램프·캐노피는 기준을 나눠줘.
같은 층의 겹친 바닥은 합집합으로 중복 제거하고,
분류되지 않은 부분과 형상 불일치는 검토 목록에 남겨줘.
원본 도면의 면적 산식과 BIM 면적은 경계가 다르면 별도 열에 써줘.
```

실제 제공 모델의299개 `IfcSpace`는 세대 식별용이며 공간 표현 형상이 없었습니다. `IfcElementQuantity`도 없었으므로 공간 속성을 단순 합산할 수 없었습니다. 유효한 슬래브 단면의 월드 좌표 XY 합집합을 사용했고 법정 전용·공용·연면적과 구분했습니다.

**도면과 치수를 연결하는 산출표 프롬프트**

```text
면적표는 숫자 표만 만들지 말고 도면·구획 번호·치수·산식을 연결해줘.
각 면적 행에서 해당 경계가 보이게 원본 평면 또는 모델 평면에 번호를 표시해줘.
산식과 단위, 포함·제외 조건, 입력 IFC 버전과 부재 GUID 근거를 넣어줘.
PDF 검토본과 수식 편집용 표를 저장하고 합계·누락·중복을 검증해줘.
법정 면적 기준이 확정되지 않은 값은 모델 검토 면적으로 명시해줘.
```

제출본에는 산정 기준, 도면과 연결된 면적표 한 장, 계산 원장, 검토 목록을 포함합니다. 화면 메시가 단면과 다를 때는 합계를 억지로 맞추지 않고 두 계산을 비교합니다. 실제 사례에서도 미세 슬래브88제품의 표시메시 불일치를 별도 공개했습니다. 해당 검토를 모든 새로운 모델의 오류 수로 반복해 적지는 않습니다.

면적표 뒤의 활용은 창호 일람, 벽·슬래브 물량, 버전별 변경, 도면 검토, 단가입력 공사비입니다. 실별 마감표에는 실 경계·실명·마감 정보가, 법정 면적표에는 산정 기준이 추가로 필요합니다. 입력이 없는 단가와 규격을 임의 확정하지 않습니다.
