# 원본 도면 대조 뷰어 실습

기존 프로젝트의 CAD Overlay Tools1.1.0과 A32 층별 검토 코드를 교육용으로 묶었습니다. `viewer-tools.zip`을 폴더 전체로 압축 해제하세요. IFC는 별도 자료실에서 필요한 유닛·층만 받습니다.

## 단위세대: CAD Overlay

1. Blender Preferences → Add-ons → Install from Disk에서 `cad-overlay-tools-1.1.0.zip`을 설치하고 **CAD Overlay Tools**를 활성화합니다.
2. 자료실의25B IFC를 Bonsai에서 엽니다. 다른 단위세대도 해당 IFC를 사용합니다.
3. 3D 뷰에서 **N → CAD Overlay**를 엽니다.
4. **도면 매핑** 파일 선택에서 `unit-references/25B/image-map.json`을 선택합니다.54B·65B·84AB는 각자 폴더를 선택합니다. IFC에 제작PC의 과거 경로가 남아 있어도 수동 선택한 경로가 우선입니다.
5. **평면 대조 / 입체 대조**, **3D 불투명도**, **바닥·슬래브도 표시**를 조절합니다.
6. **일반 모델 보기**로 비교 표시를 끕니다. 이 도구는 IFC의 형상·재료를 편집하지 않습니다.

## A32: 층별 검토

1. 예를 들어 `A32-05.ifc` 한 층을 Bonsai에서 엽니다. 전체동을 받거나 열 필요가 없습니다.
2. Blender Text Editor에서 압축 해제한 `enable-a32-viewer.py`를 열고 **Run Script**합니다. MCP로 실행할 때도 그 실제 파일 경로를 지정합니다.
3. **N → 층별 검토**를 엽니다. 단일 층 파일이면 해당 층을 자동 선택합니다. 패널의 목록에는33개 층이 있지만 현재 IFC에 없는 층은 표시할 수 없으므로 별도 IFC를 먼저 열어야 합니다.
4. **층 평면 / 층 3D · Isolate**로 모델을 보고, **원본 도면 + 모델 겹쳐 비교 / 원본 도면만 보기**로 대조합니다.
5. **모델 불투명도 / 비교 시 바닥·공간 표시**를 조절합니다.
6. **전체동 · 이전 표시 복원**은 원래 프로젝트의 버튼 이름입니다. 이 수업의 개별 층에서는 검토 전 표시를 복원하며 다른 층을 다운로드하거나 로드하지 않습니다.

5~23층은 공통 원본1개, 나머지는 해당 원본을 사용합니다. 총15종의 원본 PNG·좌표 매핑을 포함합니다. 패널은 IFC 파일 자체에 저장되지 않으므로 새 Blender 세션에서 스크립트를 다시 실행합니다. 램프 편집·전체동 실행·MCP 포트 설정은 이 묶음에 없습니다.

## 좌표와 검토 기준

이미지는 실제 CAD의 문자·치수·곡선을 포함한 렌더입니다. WCS 범위·BIM 원점·단위·층 표고에 맞춰 표시하므로 화면에 맞춰 임의 이동·축척 조절하지 않습니다. A32는 약14.44mm/픽셀,25B는 약2.78mm/픽셀입니다. 시각 비교와 정밀 치수 검사는 구분하며 치수는 DWG/DXF를 확인합니다.

평면에서 벽·창·가구 위치를, 입체에서 높이·문 위 벽·계단참을 확인하세요. 대조 전후 IFC 직렬화 내용과 저장 파일 해시가 같은지 검사합니다. 이 기능은 차이를 자동으로 판정하는 도구가 아닙니다.

## 복사해서 요청하기

```text
현재 열려 있는 단일층 IFC의 경로·층을 확인해줘. 내려받은 viewer-tools 폴더의 README를 읽고 enable-a32-viewer.py를 실행해 층별 검토 패널을 등록해줘. 현재 파일에 존재하는 층만 선택하고 원본 도면+모델 겹쳐 비교를 켜줘. 불투명도와 바닥·공간 표시를 바꿔 위치를 대조한 뒤 이전 표시로 복원해줘. IFC의 형상·재료·속성과 파일 해시가 바뀌지 않았는지 확인해줘.
```
