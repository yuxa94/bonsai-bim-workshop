# 02 · 첫 단위세대를 만들고 내 작업 스킬로 남기기

이 과정의 첫 모델은 **25B DWG를 자연어로 해석·모델링**합니다. 완성 IFC를 여는 것으로 첫 모델링 실습을 대체하지 않습니다. 제공 결과는 막힌 지점과 검토 방법을 비교할 때 사용합니다.

`{WORKSHOP_ROOT}`는 수업 자료 폴더입니다. 입력 도면의 실제 경로는 자료 목록에서 확인합니다. 출력은 `work/25b-01/`, 수정은 `work/25b-02/`처럼 새 폴더로 보관합니다.

## 첫 요청: 해석 근거부터 받기

25B 도면을 앱에 지정하고 입력합니다.

```text
이 프로젝트는 오피스텔 실별 배치 BIM 실습이야.
입력은 {WORKSHOP_ROOT} 안의 25B-v003.dwg야.
이 도면을 읽어 Blender·Bonsai의 편집 가능한 IFC로 만들고 싶어.

먼저 연결된 Blender와 열린 IFC 경로를 확인하고, 원본 DWG는 보존해줘.
DWG를 읽을 수 있는 AutoCAD 연결이 있는지 확인해줘.
직접 읽을 수 없으면 가능한 DXF 변환 방법과 필요한 자료를 알려줘.
이미지의 픽셀만 보고 정밀 좌표를 만들어냈다고 하지 말아줘.

단위·기준점·회전·벽 경계·문창·FL/SL을 읽고,
원본 관측값 / 이번 실습에서 내가 확인할 값 / 미확정 검토값을 표로 나눠줘.
미표기 수직 치수 중 실제 모델 생성에 필요한 질문을 한 번에 모아줘.
아직 완성 예제 스킬은 설치하지 말고 이번 도면의 근거로 진행해줘.
```

실제 작업에서는 DWG를 보존한 작업 복사본을 DXF로 내보내 좌표·문자·치수·블록을 함께 확인했습니다. DWG를 직접 읽는 연결이 없는 환경은 강사가 준비한 DXF를 사용하고, **DWG 직접 해석을 수행한 것처럼 기록하지 않습니다.**

원본 DXF에 `INSUNITS=0`이 있어도 바로 mm로 단정하지 않습니다. 실제 25B 사례는 프로젝트 자료와 치수 체인으로 mm를 확인했습니다. 원점·회전·축척은 IFC와 원본 참조 이미지에 동일하게 적용합니다.

## 모델 생성과 1차 확인

다음 값은 과거 25B 실습에서 사용자에게 확인받은 값입니다. 새 수강생의 실제 설계 승인이 아니므로 이번 실습에 적용할 값을 직접 선택해 답합니다.

| 과거 25B 실습 값 | 적용 범위 |
|---|---|
| 벽 2800mm·슬래브 200mm | 25B 검토 모델 |
| 미표기 창대 900mm | 별도 확인한 높은 발코니창 제외 |
| 하부장 850·식탁 750·수납장 2200mm | 해당 가구 |
| 샤워 구획 2100mm | 해당 유리 파티션과 문 |

```text
이번 25B 실습에서는 벽 2800mm, 슬래브 200mm를 검토 조건으로 적용해줘.
창호는 원본 표기를 우선하고, 미표기 창대 900mm는 벽 높이를 넘지 않는 대상에만 적용해줘.
상충하는 창은 따로 알려줘. 이 값은 다른 도면의 자동 기본값이 아니야.

벽·문·창·개구부·슬래브·공간을 IFC 클래스와 층 소속이 있는 모델로 만들어줘.
원본 CAD와 같은 좌표 변환을 사용하고 새 작업 폴더에 IFC로 저장해줘.
Save IFC 후 그 파일을 다시 읽어 스키마·형상 생성·중복 GUID를 확인해줘.
평면과 입체 화면을 보여주고 원본에서 확인한 주요 치수 3개와 대조해줘.
```

화면에 벽처럼 보이는 큐브가 있다는 것과 `IfcWall`로 저장된 부재가 있다는 것은 다른 확인입니다. IFC에서 클래스·층 소속·GUID를 읽고, 저장 후 재열기를 확인합니다. `.blend`는 표시 상태 스냅샷으로 보관할 수 있지만 IFC 원본을 대신하지 않습니다.

## 상세 수정은 한 번에 하나씩

첫 비교에서 학생이 직접 어긋난 부분을 골라 요청합니다. 아래는 실제 25B에서 보완한 주제입니다.

```text
원본 도면과 평면 정투영을 같은 좌표로 겹쳐 보여줘.
치수·문자를 포함한 실제 DXF 렌더인지, 분석용 선 그림인지 표시해줘.
현재 저장 IFC를 보존하고 새 버전에서만 수정해줘.
```

```text
발코니 WIN03을 자세히 확인해줘.
두 열의 창틀인지 복층유리 한 열인지 원본으로 구분하고,
두 열이면 각 열·창짝·유리를 독립적으로 표현해줘.
명목 폭·높이, 전체 깊이, 열 수, 개구부와 호스트를 검사해줘.
```

```text
주방 가구와 싱크를 원본 외곽과 대조해줘.
상판에는 개구부가 있고 볼 내부가 비어 보이도록 수정해줘.
가구·가전·위생기구를 알맞은 IFC 클래스로 저장하고,
수납장은 하위 구성품을 포함한 전체 높이를 측정해줘.
```

```text
욕실의 샤워 구획과 문 방향을 원본 경계·회전호로 확인해줘.
수정 대상과 유지할 GUID를 먼저 기록하고,
수정 후 대상 외 기존 부재가 유지되었는지 비교해줘.
```

수정 전후 파일, 평면·입체 이미지, 치수 근거, 미확정 항목을 `work/25b-02/`에 남깁니다. 큰 오차가 나면 객체를 화면에 맞춰 이동하기 전에 단위·OCS/WCS·미러·블록 변환을 확인합니다. 실제 25B에서는 미러 폴리선의 좌표를 잘못 해석해 약 93m 떨어진 형상이 생긴 사례가 있었습니다.

## 첫 성공 뒤 스킬 작성

스킬은 **자신의 첫 성공과 수정 기록을 재사용 가능한 지침으로 줄이는 작업**입니다. 긴 채팅을 그대로 복사하거나 25B의 모든 치수를 새 도면의 기본값으로 넣지 않습니다. 이름·설명·본문을 가진 `SKILL.md`가 기본이며, 반복 검증 코드는 필요할 때만 별도 파일로 둡니다. [OpenAI 공식 스킬 안내](https://learn.chatgpt.com/docs/build-skills)

```text
$skill-creator
방금 25B를 만들고 수정하면서 검증한 절차를 my-unit-bim 스킬로 만들어줘.
이름과 설명에는 단위세대 CAD→Bonsai IFC 작성·수정에 쓰는 스킬임을 적어줘.

내 성공 기록에서 다음을 추출해줘.
1. 실제 MCP 대상과 현재 IFC를 확인하는 법
2. CAD 단위·OCS/WCS·미러·공통 기준점 처리
3. 관측값·확인값·가정값을 구분하는 법
4. 창호·가구·샤워 상세와 IFC 저장 방법
5. 수정 범위·GUID 보존·도면 대조·재열기 검사

25B 전용 치수는 별도 사례로 분리하고 새 평면에 자동 적용하지 않도록 해줘.
먼저 {WORKSHOP_ROOT}/my-skills/my-unit-bim/SKILL.md에 작성해 보여줘.
```

초안 작성 전 [starter/unit-bim/SKILL.md](../skill-kits/starter/unit-bim/SKILL.md)의 질문을 채울 수 있습니다. 작성 뒤에만 [completed/unit-bim/SKILL.md](../skill-kits/completed/unit-bim/SKILL.md)와 비교합니다. completed는 강의용 참고 예제이며 모든 도면에서 동작한 만능 변환기는 아닙니다.

학생이 만든 스킬 이름은 `my-unit-bim`입니다. 제공 완성 예제의 파일 경로는 `skill-kits/completed/unit-bim/SKILL.md`이고 YAML의 이름은 `workshop-unit-bim`입니다. 폴더를 읽어 비교할 때는 정확한 파일 경로를, 등록 뒤 호출할 때는 YAML의 이름을 사용합니다. 예제를 별도로 설치한다면 설치 폴더 이름도 `workshop-unit-bim`으로 맞춥니다. 층 예제도 `completed/floor-bim/SKILL.md` → `workshop-floor-bim`으로 같은 원리를 따릅니다.

개인 스킬 등록은 현재 앱이 탐색하는 폴더를 확인해 진행합니다. 확인 시점 공식 Codex 문서는 사용자 `$HOME/.agents/skills`와 프로젝트 `.agents/skills`를 안내합니다. 이 프로젝트의 과거 환경은 `.codex/skills`를 사용했으므로 해당 경로를 다른 PC의 현재 기본값으로 간주하지 않습니다. 수업의 원본 `my-skills/`와 설치 사본을 구분하고, 같은 이름의 기존 스킬을 덮어쓰기 전에 차이를 확인합니다.

```text
방금 작성한 my-unit-bim을 이 앱에서 개인 스킬로 쓸 수 있게 등록해줘.
현재 지원되는 스킬 경로를 확인하고 기존 동명 폴더가 있으면 먼저 비교해줘.
내가 만든 원본은 수업 폴더에 유지하고 관련 스킬 폴더만 복사해줘.
앱의 인증 파일·전체 설정·다른 스킬은 복사하지 마.
등록 후 목록에서 발견되는지 확인해줘.
```

## 54B에 적용하고 스킬을 고치기

```text
$my-unit-bim
이번에는 {WORKSHOP_ROOT} 안의 54B-v003.dwg로 두 번째 단위세대를 만들어줘.
25B 장면과 IFC는 유지하고 별도 작업 폴더와 Blender 세션을 사용해줘.
먼저 연결 대상·원본 치수·벽 레이어·창호 열 수·FL/SL을 새로 확인해줘.
25B의 높이·재료·가구 크기를 54B의 승인값으로 취급하지 마.
재사용할 부재는 후보를 보여주고 54B 치수에 맞게 IFC 형상을 작성해줘.
원본 에셋은 보존하고 새 인스턴스에는 새 GUID를 부여해줘.
저장 IFC와 평면·입체 검증을 전달해줘.
```

실제 54B에서는 25B 식탁을 그대로 확대하지 않고 54B의 700×1200mm에 맞춰 IFC 단면을 작성했습니다. 원본 레이어를 다시 확인해 같은 벽 위치의 하부 경량벽과 상부 콘크리트도 나눴습니다. 스킬의 효과는 두 번째 도면에서 이런 차이를 찾아내고 새 근거에 맞게 적용했는지로 판단합니다.

시간이 부족하면 54B의 벽·문창과 상세 하나를 직접 검증하고, 65B·84AB는 제공 결과로 타입별 차이와 보관 구조를 살펴봅니다. **직접 생성한 결과와 제공 예제를 열어본 결과는 제출 기록에서 구분합니다.** 다음 단계는 [기준층·반복층·면적표](03-floor-reuse-and-area.md)입니다.
