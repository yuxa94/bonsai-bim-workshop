# 동평면의 기준층·반복층·산출 근거

실제 도면의 세대 배치와 공용부를 보존하며 층별 편집과 저장 IFC의 검토 근거를 연결한다. 첫 기준층 성공 뒤 비교하는 강의용 예제다.

## 기준층 작성과 수정

1. 실제 MCP 세션의 IFC 경로·포트·변경 상태를 확인한다. 기존 세대와 기준층 장면을 보존한다. 현재 IFC 수정은 그 파일의 작업 버전을 이어가고, 다른 층 신규 작성은 별도 작업 사본을 사용한다.
2. CAD 단위·WCS 원점·회전·중첩 블록·미러 변환을 읽고 대상 평면 범위를 한정한다. 원본 INSERT로 세대수와 타입별 수를 대조한다. 도면 밖 참조까지 모두 모델링하지 않는다.
3. 설계 타입과 방향·미러·외벽 조건이 다른 배치형을 구분한다. 복도·코어·경계를 지나는 벽 등 공용부를 세대와 분리한다. 유사 단위세대 타입으로 원본 배치를 임의 대체하지 않는다.
4. 층 레벨은 단면의 실제 치수 끝점과 레벨 기준으로 산정한다. 문자 배치 위치를 레벨 좌표로 쓰지 않는다. FL/SL 상충과 미표기 계단·옥상 상세는 검토 항목으로 남긴다.
5. 벽·슬래브·문창·계단·승강기의 클래스·층 소속·개구 관계를 유지한다. 계단 압출 Depth가 폭인지 상승 높이인지 로컬 축을 확인한다. UP/DN 두 표시를 같은 층간 계단 두 벌로 복제하지 않는다.

## 재사용 데이터와 편집

- 검증한 기준층 수정본을 불변 버전으로 보관한다. 편집에는 작업 사본을 사용하고 보관본·해시·형상·속성·재료·조립체 구성을 연결한 카탈로그를 둔다.
- 같은 배치형의 반복에는 네이티브 IFC 타입·매핑 형상을 사용할 수 있다. 새 물리 발생 객체는 새 GUID를 가진다. 원본 핸들만으로 키를 만들지 말고 층·발생 위치를 포함해 중복을 검사한다.
- 통합 IFC와 층별 IFC의 같은 부재는 GUID·월드 배치가 같도록 유지한다. 전체 세대를 제조사 IFC 부재 타입 하나라고 설명하지 않는다.
- 타입 원본 편집은 해당 반복 배치에 적용한다. 특정 층 예외는 그 층의 편집본을 우선하며 적용 범위를 기록한다. 재조립 전 작업 사본 변경과 층 예외를 확인한다. 외부 IFC 자동 동기화나 양방향 병합을 가정하지 않는다.
- IFC 재료 관계와 화면 스타일을 각각 확인한다. 원점에 겹쳐 보이는 타입 작성용 메시를 실제 발생 객체와 구분한다.

## 검증

저장 IFC 재열기·스키마·형상 생성·중복 GUID·층 소속을 검사한다. 원본 세대수와 층 레벨, 대표 배치의 미러와 창호 방향, 공용부 경계를 대조한다. 통합본과 층별 파일의 GUID·월드 좌표를 비교한다.

별도 시험 사본에서 공유 타입 편집이 반복층 두 곳에 반영되는지, 한 층 예외가 유지되는지 실제로 확인한다. 화면 토글과 원본 도면 겹치기는 표시 동작이며 IFC 편집 완료와 구분한다. 검증된 모델 범위와 미확정 설계 항목을 전달한다.

## 모델 면적표

저장된 입력 IFC의 버전·SHA256을 고정해 읽기 전용으로 분석한다. IfcSpace의 형상·면적 수량 유무를 먼저 조사한다. 타입명의 숫자를 면적으로 사용하지 않는다. 형상이 없다면 사용할 기하와 경계를 명시한다.

슬래브 기반 수평 XY 투영면적을 사용할 경우 단위를 환산하고 월드 배치를 적용해 층별 합집합으로 중복을 제거한다. 일반 바닥·계단참·지붕·램프·캐노피와 미등록 영역을 산정 기준에 따라 구분한다. 유효 단면과 메시가 다르면 GUID별 검토 목록을 남긴다.

산출표는 도면·구획 번호·치수·산식·단위·부재 GUID·합계 검증을 연결한다. 원본 치수 산식과 BIM 기하의 경계가 다르면 별도 열에 둔다. 법정 면적 기준과 실별 구획이 미확정이면 모델 검토 면적으로 명시한다. 규격·단가가 없는 항목은 입력란으로 둔다.
