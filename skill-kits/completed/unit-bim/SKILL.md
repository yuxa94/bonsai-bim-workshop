# 단위세대 CAD에서 검토용 IFC 작성

도면 근거와 IFC의 편집 가능한 데이터를 함께 보존한다. 첫 실습 뒤 자신의 스킬과 비교하는 강의용 예제이며 도면 자동 인식기나 설계 승인 기준은 아니다.

## 시작 조건

1. MCP가 실제로 연결한 Blender의 버전·세션·현재 IFC 경로·변경 상태를 읽는다. 여러 창이면 포트를 확인한다. 다른 세대 장면을 비우거나 교체하지 않는다.
2. 원본 CAD를 보존하고 작업 복사본을 읽는다. DWG 연결이 없으면 DXF 변환 또는 제공 DXF를 사용하고 실제 입력 방식을 기록한다.
3. 단위·WCS 기준점·회전·블록의 미러와 OCS→WCS 변환을 확인한다. IFC와 도면 참조에 하나의 변환을 사용한다.

## 도면에서 모델로

- 벽면·문창 경계·가구 윤곽·실명·FL/SL을 원본 핸들 또는 치수 근거와 연결한다. 닫히지 않은 벽은 폐합 제안임을 구분한다.
- 형상에 필요한 미표기 높이·창대·재료는 해당 도면의 확인값을 사용한다. 관측값·사용자 확인값·검토 가정을 구분해 속성과 기록에 남긴다. 이전 예제의 높이를 새 도면에 자동 적용하지 않는다.
- 벽·슬래브·문·창·공간은 IFC 클래스와 공간 계층을 갖게 한다. 개구부의 호스트·문창 채움 관계를 확인한다. 가구·가전·위생기구도 맞는 IFC 클래스로 작성하고 구성품을 집계한다.
- 이중창은 두 열 프레임인지 복층유리인지 원본에서 구분한다. 두 열이면 각 열·창짝·유리를 구성하고 전체 깊이·명목 치수·개구부를 각각 검증한다.
- 싱크와 세면기는 상판 개구와 빈 볼 내부를 맞춘다. 샤워 구획은 방 전체 벽과 구분하고 경계·높이·문 회전호를 확인한다.
- 재사용 부재는 원본 에셋과 새 배치의 출처를 따로 남긴다. 새 발생 객체에 새 GUID를 부여하며 도면별 폭·깊이는 IFC 단면이나 표현에서 조정한다.

## 기존 모델 수정

현재 IFC를 새 작업 버전으로 보존하고 대상 GUID·요청 변경·유지할 범위를 기록한다. IFC 속성·파라미터·표현을 갱신한다. 화면 메시만 바꾼 상태를 저장 IFC 완료로 취급하지 않는다. IFC를 BIM 원본으로 열고 Save IFC로 저장한다. blend는 표시 스냅샷이다.

## 완료 증거

- 새 저장 IFC 재열기, 스키마·중복 GUID·형상 생성 검사.
- 원본과 같은 좌표의 정투영 평면 및 입체 대조. 치수·문자가 포함된 원본 DXF 렌더와 분석용 이미지를 구분한다.
- 주요 수치와 상세의 직접 측정, 범위 밖 GUID·형상 보존 비교.
- 실제 연결된 Bonsai에서 파일 경로·표시 누락·편집 가능 여부 확인.
- 입력·출력 버전, 확인값과 가정값, 실행한 검사와 남은 상세 전달.

스키마 통과는 치수·법규·시공 상세의 정확성을 증명하지 않는다. 검사를 실행하지 못한 항목은 확인되지 않은 상태로 남긴다.
