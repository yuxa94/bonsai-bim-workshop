# 단위세대 BIM 스킬 작성용 초안

이 파일은 첫 25B 모델과 상세 수정이 성공한 뒤 채우는 학습용 초안이다. 확인하지 않은 내용을 완료한 규칙으로 쓰지 않는다. 작성한 파일은 `my-unit-bim/SKILL.md`로 보관하고 이름과 설명을 사용 목적에 맞게 바꾼다.

## 적용 범위

다음 질문에 자신의 실제 작업을 근거로 답해 문장으로 바꾼다.

- 어떤 입력에서 사용하는가? DWG를 읽은 도구 또는 DXF 변환 방법은 무엇인가?
- 모델 작성과 기존 IFC 수정 중 무엇을 지원하는가?
- AutoCAD 평면 작도만 요청한 경우에도 이 스킬이 필요한가?

## 작업 전 확인

- 내가 실제로 조회한 Blender 버전·포트·IFC 경로는 무엇인가?
- 원본·현재 모델·미저장 작업을 어떻게 보존했는가?
- CAD 단위·기준점·회전과 OCS/WCS·미러를 어떻게 확인했는가?

## 모델 작성과 수정

- 원본 관측값·수업 확인값·검토 가정을 어디에 기록했는가?
- IFC 클래스·층 소속·개구부·가구 집계를 어떻게 다뤘는가?
- 이중창·싱크·샤워 구획 중 실제로 수정한 항목의 핵심은 무엇인가?
- 수정 시 유지할 부재와 바꿀 부재를 어떻게 정했는가?

## 검증과 전달

- 저장 후 다시 연 IFC에서 무엇을 확인했는가?
- 평면·입체·치수 대조는 각각 무엇을 증명했는가?
- 기존 GUID와 범위 밖 형상을 어떻게 비교했는가?
- 다음 54B에서 새로 읽어야 할 값은 무엇인가?

25B의 치수와 핸들은 사례 참고 자료로 분리한다. 다음 도면에 적용한 뒤 실제로 도움이 된 규칙과 빠진 규칙을 고쳐 완성한다.
