# 기준층·반복층 BIM 스킬 작성용 초안

기준층 한 층의 실제 생성·수정이 끝난 뒤 자신의 기록으로 채운다. 단위세대 스킬과 공통인 설명은 줄이고 동평면에 필요한 판단을 쓴다. 아직 실행하지 않은 반복·면적 기능은 후속 검증으로 표시한다.

## 입력과 적용 범위

- 실제 동평면 DWG/DXF의 어느 범위를 모델링했는가?
- 기준층 한 층과 파일명에 적힌 층 범위를 어떻게 구분했는가?
- 동단면·동입면 중 층고 근거로 읽은 자료는 무엇인가?

## 층 작성

- 세대 INSERT·중첩·미러를 어떤 변환으로 읽었는가?
- 설계 타입·방향별 배치형·공용부를 어떻게 나눴는가?
- 레벨·FL/SL·계단·승강기에서 관측·확인·가정값은 무엇인가?
- 기존 기준층을 수정할 때 현재 IFC와 GUID를 어떻게 보존했는가?

## 재사용과 예외

- 불변 보관본과 편집용 사본은 어떻게 구분하는가?
- 타입 원본 편집과 한 층 예외의 적용 범위는 무엇인가?
- 새 발생 객체와 통합/층별 파일의 같은 부재 GUID를 어떻게 다루는가?
- 다시 조립할 때 예외 편집이 유지되는지 무엇으로 검사하는가?

## 검증과 산출

- 원본 세대수·층 레벨·층 소속·형상·재료·좌표를 어떻게 대조했는가?
- 면적표에 실제로 사용할 수 있는 공간 형상이나 수량이 있는가?
- 면적 경계·중복 제거·제외 항목·도면 번호·GUID 근거를 어떻게 남기는가?

다른 층 하나에 적용하고 반복층 두 곳과 예외 한 곳을 실제로 확인한 결과로 보완한다.
